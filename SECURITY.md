## Reporting a Vulnerability

If you discover a security vulnerability in **Hermes Droid** or the companion Android node:
1. **Do not open a public GitHub issue.**
2. Send an advisory report with reproduction steps to the project maintainers.
3. We follow standard responsible disclosure practices and will acknowledge receipt within 24 hours and provide an estimated remediation timeline.
